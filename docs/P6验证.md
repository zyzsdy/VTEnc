# P6：字幕、颜色标签与静态 HDR 元数据验证

日期：2026-11-17。结论仅覆盖下列设备、系统、配置和样本；没有运行全量测试。

## 环境与依赖

- Apple M6，原生 arm64；macOS 27.2.1（26B131），Apple Clang 21 / macOS SDK 27.2。
- CMake dev preset；libass 0.17.5_1、FreeType 2.15.0、HarfBuzz 15.0.0_1、FriBidi 1.0.18、libunibreak 8.0；FFmpeg 9.0.2 用于独立解码／探测／remux。

- 已核对 NVEnc `5bb35d860bc5f877b01fe60e4de5ac756b9b80ed` 的 `NVEncFilterSubburn.cpp`（MIT），以及本机安装的 libass COPYING（ISC）、FreeType LICENSE.TXT（FTL/GPL 双选）、HarfBuzz COPYING（Old MIT）、FriBidi COPYING（LGPL 2.1）。声明见 [第三方说明](../THIRD_PARTY_NOTICES.md)。

| --- | --- |

| HDR 字幕白 | 不透明白块 203 cd/m²，以及不同颜色／透明度、100/203 cd/m² 图层交叠，与独立 PQ EOTF、HLG 1000-nit / gamma 1.2 参考一致 |
| 字形掩码 | 检查 stride 最后一行仅分配 width 字节、负坐标、奇数裁剪、多层顺序、字形 alpha、用户 opacity；没有越界读取或 CPU 视频合成 |
| 缓存与空图层 | 静态 libass 图像的 changed=false；重复 GPU 合成保留缓存结果；字幕消失直接保留源像素，重新出现时正确重建 |
| ASS/SSA 中文 | 两种脚本均实测中文、开始／结束边界；ASS 实测粗体、斜体、描边、阴影、运动、旋转、淡入淡出、内部裁剪及叠加 |

## 颜色、HDR 与封装

| 检查 | 结果 |
| --- | --- |
| 仅标签修正 | 改 matrix/transfer/primaries 后 ffprobe 标签符合请求；与基线的解码 framemd5 完全相同，证明没有隐含像素转换 |
| HDR10 保留 | 现有 HDR10 HEVC Main10 样本分别 `--avsw`、`--avhw` 转码，独立解码后的 mastering display 与 CLL 完整相同，包括源 MaxCLL=0、MaxFALL=0 |
| 静态数据清除 | `--hdr-metadata clear`、HDR→SDR、PQ 字幕烧录后均不存在失效静态 HDR side data；preserve + 字幕在准备输出前明确失败 |
| 显式设置 | 缩放后设置 1000-nit mastering display、MaxCLL=1000 / MaxFALL=400，独立解码 SEI 核对通过 |
| PQ/HLG 烧录 | HDR10 HEVC 与 HLG AV1 10-bit 输入均通过字幕 + HEVC Main10 硬编及完整解码；HLG 源缺色度位置，测试显式指定 `--input-chroma-loc left`，未猜测 |
| 参数集 | H.264/HEVC 的裸文件、TS、裸 stdout、TS stdout：逐个同步 packet 检查 SPS/PPS，HEVC 另检查 VPS，均重复存在；每种配置至少六个同步帧 |
| MP4/MOV | avcC/hvcC 存在；逐个同步 packet 确认没有强行插入 in-band 参数集；HEVC 使用 hvc1。全部输出经过 FFmpeg `-xerror` 完整解码 |

发现并处理的系统行为：CoreVideo 会省略全零 Content Light 附件。软件解码从 AVFrame side data 保留原始证据，硬解在调度线程读取源 HEVC SEI；图像转换后的标准 HDR 附件清除，证据另存。最终编码包中的静态 SEI 按确定的输出策略整理，因此不会将“属性设置成功”误当成“真实码流有该信息”。此步骤不修改压缩图像数据、不调用软件视频编码器。

## 已声明边界

- 外部 UTF-8 ASS/SSA，最多 8 层；不支持内嵌软字幕选择、附件字体自动提取、SRT/位图字幕转换或 NVEnc 全参数兼容。
- 只接受已有 NV12/P010 管线；原始帧 CLI 的字幕／P6 元数据参数明确拒绝，可使用 avformat/Y4M 路径。
- 字幕按最终存储尺寸／SAR 布局；显示旋转会一起旋转字幕，不承诺旋转画面中的自动正向字幕。
- HDR 使用文档中确定的字幕白、PQ 和 HLG 显示模型；不涵盖 Dolby Vision、HDR10+、动态 mastering 元数据或任意 HLG 显示峰值。
- 当前采样布局和掩码合成经数值验证，不代表 libass / NVEnc / VSFilter 的所有历史行为逐像素兼容；HDR 字幕不采用旧式 ASS YCbCr mangling。
- 未做长片吞吐量、所有分辨率／硬件组合或其他 macOS 版本的性能和兼容性承诺。
